## Fixes Applied

### 1. XSS: HTML-escaped popupHtml (HIGH Security)
**File:** `client/components/seismic/MapCanvas.tsx`

Added `escapeHtml()` helper; applied to all interpolated values in `popupHtml()` (survey hover popups, uploaded layers popup rows). Prevents `project_name` or `si_code` containing `<script>` from executing.

### 2. keydown guard during draw mode (MEDIUM UX)
**File:** `client/components/seismic/MapCanvas.tsx`

Window `keydown` handler now checks `e.target.tagName` for `INPUT`, `TEXTAREA`, `SELECT` and `isContentEditable`, ignoring `Enter`/`Escape` during typing while draw mode is active. Prevents accidental polygon finish when pressing Enter in a text field.

### 3. ZodError → HTTP 400 (MEDIUM API)
**File:** `server/src/index.ts`

Global error handler now maps `ZodError` to HTTP 400 with `{error: "Validation failed", issues}`. Previously returned generic HTTP 500.

### 4. Server-side JSON.parse of ST_AsGeoJSON (LOW API)
**Files:** `server/src/routes/surveys.ts`, `client/lib/seismic.ts`, `client/components/seismic/MapCanvas.tsx`

Server now parses `ST_AsGeoJSON` strings in GET `/api/surveys`, returning GeoJSON objects directly. Client types updated to `GeoJSON.Geometry | string | null`. Parse sites handle both string and object defensively.

### 5. downloadPdf extraction (CODE QUALITY)
**Files:** `client/lib/seismic.ts`, `client/app/page.tsx`

Inline PDF download fetch extracted to typed `downloadPdf(rec: SurveyRecord)` function in `lib/seismic.ts`. Implements NotebookLM's #1 recommendation: typed API client hooks.

### 6. Panel persistence race fix
**File:** `client/components/ui/resizable.tsx`

Fixed race where first `onLayoutChanged` fires synchronously during render (before effect runs), clobbering stored layout with default. Added `mountTimeRef` guard: suppresses saves for first 1000ms after mount. Also removed debug console.log statements.

### 7. SRID 4326 on interpretation geometry (CRITICAL)
**File:** `server/src/routes/interpretation.ts`

`ST_GeomFromGeoJSON($9)` in both INSERT (line 92) and UPDATE (line 139) was missing `ST_SetSRID(..., 4326)`. PostGIS defaults to SRID 0, causing SRID mismatch with `processing_records.footprint` (SRID 4326) in `ST_Intersects` joins — returns zero results or errors. Fixed both routes.

### 8. MapCanvas error boundary
**Files:** `client/components/seismic/MapErrorBoundary.tsx`, `client/app/page.tsx`

Wrapped `MapCanvas` in a React Error Boundary. If MapLibre WebGL fails to load or workers crash, shows a fallback UI with "Reload map" button instead of white-screening the entire app.

### 9. Graceful shutdown
**File:** `server/src/index.ts`

Added `SIGTERM`/`SIGINT` handlers that call `server.close()` to drain connections before exit. Prevents abrupt connection severing during container restarts or long-running `/reprocess` tasks.

### 10. Transactional reprocess (bulk data integrity)
**Files:** `server/src/db.ts`, `server/src/routes/surveys.ts`

Added `withTransaction(fn)` helper to db.ts that acquires a single client, runs BEGIN/COMMIT/ROLLBACK, and releases. Wrapped the `/reprocess` loop inside a single transaction — if any record fails, all changes roll back, preventing partial updates.

### 11. Bulk layer features endpoint (N+1 fix)
**Files:** `server/src/routes/layers.ts`, `client/lib/layers.ts`, `client/app/page.tsx`

Added `GET /api/layers/batch/features?ids=1,4,7` that returns features for multiple layers in a single query using `WHERE layer_id = ANY($1::int[])`. Frontend updated from `useQueries` (N separate requests) to a single `useQuery` with `fetchBulkFeatures`. Eliminates request waterfall for 10-15 shapefile layers.

### 12. Geometry split-brain unification
**File:** `server/src/routes/surveys.ts`

Removed the ST_MakeEnvelope fallback that invented fake bounding boxes (0.1° around centroid or bbox-derived polygons) when `footprint` was null. Now uses `COALESCE(r.footprint, r.centroid_geom)` — returns the real footprint if available, or the centroid as a POINT geometry. Frontend already handles Point geometries via `survey-point-2d` circle layer. Surveys with neither footprint nor centroid return null (not shown on map).

### 13. Interpretation link query COALESCE fix
**File:** `server/src/routes/interpretation.ts`

Updated `GET /:id/surveys` to use `ST_Intersects(COALESCE(r.footprint, r.centroid_geom), ip.geometry)` so point-only surveys (7 records) are correctly linked to interpretation polygons that contain their centroid.

### 14. Security headers (helmet CSP)
**File:** `server/src/index.ts`

Added `helmet` middleware with Content Security Policy allowing tile sources (OpenStreetMap, Carto, ESRI), Google Fonts, blob: workers, and localhost:4000 API. Also sets HSTS, X-Frame-Options, X-Content-Type-Options.

### 15. MAD outlier detection in selectFootprintCorners
**File:** `server/src/lib/reproject.ts`

Added Median Absolute Deviation (MAD) outlier detection before the adaptive gap split. Calculates centroid of all corners, distances to centroid, median distance, and MAD. Corners exceeding median + 3*MAD are flagged and dropped (digit-entry typo detection). Replaces the brittle 500km/4x threshold for single-outlier cases.
